# My Journal App

A simple journal application built with HTML, CSS, and JavaScript.

## Features

- Create journal entries
- Edit existing entries
- Delete journal entries
- Search journal entries
- Filter by category
- Mark entries as favorites
- Sort journal entries
- Save entries using localStorage

## Technologies Used

- HTML
- CSS
- JavaScript
- Browser localStorage

## Purpose

This project was built as a practical exercise in learning JavaScript, DOM manipulation, and browser storage.
